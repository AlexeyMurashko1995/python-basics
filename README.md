## 🏗 Featured Projects

### 1. SmartFlow AI — Enterprise Sales Analytics API *(In Active Development)*
An asynchronous backend engine built to process, aggregate, and analyze high-volume sales transactions in real time.
* **Key features:** Advanced SQL aggregation pipelines using SQLAlchemy 2.0 (`JOIN`, `GROUP BY`, `HAVING` queries), Alembic database migration management, fully asynchronous PostgreSQL workflow, and Docker containerization.

### 2. Launchpad AI — Asynchronous Startup Valuation API
An asynchronous REST API for AI-driven startup viability scoring and technical analysis.
* **Key features:** JWT Authentication & authorization, Passlib (Bcrypt) password hashing, non-blocking `BackgroundTasks` for LLM analytics, and strict Pydantic v2 payload validation.

### 3. AI-Powered Warehouse Hub & Parcel Tracker
A functional REST API backend for automated cargo delivery tracking and regional hub management.
* **Key features:** Real-time parcel classification via asynchronous `HTTPX` requests to European LLMs (`mistral-small-latest`), One-to-Many relational database structure, and role-tailored response schemas.

### 4. Warsaw Housing Market AI Analyzer
A production-ready data science project designed to scrape, clean, analyze, and predict apartment prices in Warsaw, Poland.
* **Key features:** Custom web scraper using `BeautifulSoup4`, median-based outlier filtering, and a trained Linear Regression model achieving an R² Score of `0.787`.
